# Tulkarm Municipality Library Management System — Frontend

This repository contains the React frontend application for a municipal public-library system.

The application source is in [`LibraryProject-main/`](./LibraryProject-main/). Start there for setup instructions, technology details, API integration notes, and the current frontend feature map.

## Related applications

The project is represented across several repositories:

| Repository | Scope |
| --- | --- |
| [front](https://github.com/OJK22/front) | Main frontend, including public pages and library workflows |
| [books](https://github.com/OJK22/books) | Book catalog and circulation administration UI |
| [admin](https://github.com/OJK22/admin) | Staff, groups, and permission administration UI |
| [loan](https://github.com/OJK22/loan) | Experimental lending and subscription prototype |

The repositories are related in subject matter, but they are separate frontend codebases. The `loan` repository is explicitly experimental and must not be treated as a production component.

## Project status

The frontends depend on separately hosted API services. This repository does not include the ASP.NET Core backend or SQL Server database. See the nested README for development setup and security considerations.
